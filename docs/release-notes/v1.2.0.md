# 🍼 Mamadera v1.2.0 — Release Notes

**Growth + per-baby reminders.** v1.2.0 is the first release since the baby-profile
work: the app can now follow several babies independently, and it gains a third
measurement axis (weight / height / temperature) on top of feedings, sleep and
diapers.

- **App version** `1.2.0`, **store build** `1.2.0+9` (build numbers are monotonic:
  v1.1.1 shipped at +6, rc builds reached +8 — `pubspec.yaml`, `app_config.dart`).
- **Drift schema v10 → v11** — `measurements` and `reminder_completions` tables;
  `reminder_settings`, `reminder_dismissals` and `custom_reminders` re-keyed per baby.
- **Backup export format v1 → v2** — seven sections, baby-scoped rows, `measurements`
  and `reminder_completions` included (encrypted values decrypted only in the mapper).
  `exportFormatVersion` bumped in the exporter, supported version in the importer.

## ✨ New features

- **Growth tracking** — weight, height and temperature from three new home-screen
  buttons; values encrypted at rest with the existing `EncryptionService`
  (AES-GCM in a `TEXT` column, never plaintext REAL). Weight in 10-g steps, height
  in cm, temperature in tenths of a degree, each sheet defaulting to a sane start
  value (temperature opens at 37, not 0). Out-of-range values get feedback, not a
  silent write.
- **Growth screen** (`/growth`) — the latest value of each measurement plus the full
  history. Not a 6th `HistoryFilter` chip: growth is not a care event.
- **Reminders scoped per baby** — settings, dismissals and completions are keyed by
  `(baby_id, item_id)`. Switching one off, dismissing or completing it for one baby
  no longer does it for the others.
- **Manual completion + detached reminders** — custom reminders may have no care
  attached ("No care" → `subtype_value NULL`, `completion_source='manual'`) and are
  marked done with one tap from the due list.
- **Due reminders on Home** — the list of due reminders renders under the tracking
  buttons, where the old « +2 » pill stopped being readable.
- **Solid feeding subtype** — quantity entered in grams.
- **`+/-` steppers** on every numeric input.
- **Baby name on Home** — the active baby's name in the AppBar title, so reminders
  are not anonymous (with the Android `LaunchTheme` restored on the way in).

## 🔐 Privacy

No new dependency, no network, no telemetry. Growth values are sensitive health
data and are encrypted at rest, the same way notes already are. The manual JSON
export remains the only sanctioned data exit, and it now covers the new tables —
a backup that silently omitted `measurements` would have been a broken backup.

### Known behaviour on upgrade (by design, recorded)

Upgraded installs surface reminder state per baby strictly — rows written before
v1.2.0 survive under `baby_id=''` and still export, but a preset a user had switched
off in v1.1.1 is due again after upgrading, and old detached reminders leave Home
until re-created. Documented in `reminders_repository_impl.dart` and in the patch
notes ("Keep reminders independent per baby").
