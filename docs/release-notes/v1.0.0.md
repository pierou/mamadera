# 🍼 Mamadera v1.0.0 — Release Notes

**First stable release of Mamadera, a privacy-first newborn tracking app.** Track feedings, sleep, diaper changes, and health routines — all stored locally on your device with end-to-end encryption. No cloud, no telemetry, no tracking.

---

## ✨ New Features

### 👶 Baby Profiles
- Create, edit, delete baby profiles with active profile selection
- Duplicate name validation to prevent conflicts
- Cascade-aware deletion of associated data

### 📊 Tracking & History
- **Feedings** — Track breastfeeding and bottle feedings with duration logging and optional notes
- **Sleep** — Log naps and nighttime sleep sessions with start/end timestamps
- **Diapers** — Record wet or dirty diaper changes at a glance, including localized color chips (PipiColor / CacaColor)
- **Health routines** — Track eye/face/nose cleaning, belly button care, Vitamin D (daily), and Vitamin K (every 30 days rolling interval) with reminder pills for overdue items
- **Reminders** — Periodic health reminders with dismissal cooldowns; supports daily, weekly, monthly, and custom intervals

### 🏠 Home Screen
- Quick-access tracking entry point for all event types
- Duration picker, reminder pills, quantity fields for feeding events
- Shared icon mappings across all tracking types and subtypes

### 📜 History Browser
- Chronological event browsing with filter by type
- Inline editing and deletion support
- Quantity field in tracking event creation

### 🔔 Onboarding & Info
- First-launch Terms of Service acceptance flow (localized markdown content)
- App access gated until terms accepted via router guards
- Version-update patch notes dialog on app upgrade, loaded from locale-specific JSON assets with opt-out preference
- Info screen with app details and attributions
- Feedback screen for bug reports and feature suggestions (email & GitHub submission)

### ⚙️ Settings
- Language selector: French 🇫🇷 / English 🇬🇧 / Spanish 🇪🇸
- Theme mode toggle: Light ☀️ / Dark 🌙 / System 💻
- Database reset option with confirmation flow

---

## 🔒 Privacy & Security

- **Offline-first** — all data stays on your device, zero telemetry
- **Encryption at rest** — sensitive notes encrypted with AES-GCM via `flutter_secure_storage` before DB insert
- **Minimal permissions** — none by default; no background tracking
- **GDPR/CCPA/COPPA ready** — compliance out-of-the-box with no data collection

---

## 🏗️ Under the Hood

### Architecture & Code Quality
- Feature-first Clean Architecture with repository pattern
- Riverpod `StateNotifier` / `AsyncNotifier` for state management (no mixin-based patterns)
- Drift ORM for local SQLite database, versioned migrations up to v3 with primary key constraints
- Freezed + json_serializable models with build_runner codegen
- Strict analysis options: zero warnings allowed in CI

### Database & Models
- Nullable timestamps removed from repositories for cleaner data model
- Feeding event refactored (removed duration property, added quantity field)
- Health label resolver implementation across all health subtypes
- Reminder logic updated to return last tracked event regardless of date

### Build & Distribution
- AAB and IPA build targets in Makefile (`make build-android`, `make build-ios`)
- Release signing configured for Android (build.gradle.kts)
- F-Droid metadata with app description and key features
- Info.plist encryption settings for iOS
- Gradle toolchain configuration for improved cross-platform builds

### Testing
- Comprehensive widget tests: FeedbackScreen, TermsScreen, TrackButton, ReminderPill, waste dialog components
- Flutter Driver integration tests: navigation flow, feeding tracking, history browsing, onboarding, rendering validation with full-screen checks
- ≥ 80% line coverage enforcement in CI for domain/ and data/ layers
