# 🍼 Mamadera v1.1.1 — Release Notes

**A fix-forward on v1.1.0** — the reminders release that went live on Google
Play on 2026-09-15. v1.1.1 is also the **first build submitted to the Apple
App Store**: fresh iOS installs get the complete v1.1.0 feature set (custom
reminders, preset toggles, stool texture, backdated logging, JSON
export/restore, full Spanish support) plus the fixes below.

---

## 🐛 Bug Fixes

- **Stale reminder pill** — a reminder switched off in Settings (preset toggle
  or custom-reminder edit) now disappears from the Home screen immediately
  instead of lingering until the next poll. The settings write path used to
  nudge the home notifier with a one-shot invalidation while the reminders
  service was still resolving pre-toggle data, so the stale due-list committed;
  the home build now awaits the settled service (`b995e10`).
- The unreachable 4 h dismiss-cooldown path (zero callers at release time) was
  removed along with the fix.

## 🍎 App Store (first iOS submission)

- **Export compliance** — `ITSAppUsesNonExemptEncryption = false` in
  `ios/Runner/Info.plist`, matching the "no non-exempt encryption" declaration
  in App Store Connect: the app only uses publicly available cryptographic
  libraries (exempt under Apple's declaration) and its keys never leave the
  device (`6e557c7`).
- **Build `1.1.1+6`** — build number 5 was already consumed in ASC by the
  1.1.0 retrigger archive, and Apple requires a strictly increasing build
  number per app.
- Xcode Cloud remains the only iOS build path: push to `main` → post-clone
  hook (Flutter 3.44.8 + generated SPM package) → auto-signed archive in ASC.
- Store media: localized screenshot pipeline in
  [`screenshots/ios/asc/README.md`](../screenshots/ios/asc/README.md), promo
  images generated by [`mamadera_banner_final.py`](../mamadera_banner_final.py).
