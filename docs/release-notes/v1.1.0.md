# 🍼 Mamadera v1.1.0 — Release Notes

**Your baby's routine, your rules — and now backed up.** Custom reminders tied to the cares you actually give, the ability to silence presets you don't need, finer-grained tracking, and a full export/restore so your data can finally travel with you — still without ever touching a cloud.

---

## ✨ New Features

### 🔔 Reminders, your way
- **Custom reminders** — create your own reminders tied to a care (e.g. every evening at 8 pm), on top of the built-in health routines
- **Quiet the presets** — switch off preset reminders you don't need without losing your custom ones
- Reminders now honour the configured day of the week and are scoped to the currently selected baby

### 📊 Finer tracking
- **Stool texture** — record texture on dirty-diaper changes, fully localized
- **Backdated logging** — choose the exact date and time when adding an event, for 3 a.m. memories filed at breakfast

### 💾 Backup & restore
- **Export everything** — all data as a single JSON file from the in-app menu, shared through the OS share sheet (AirDrop, Drive, Files… your choice)
- **Restore the whole database** — pick a previously exported backup file and Mamadera rebuilds itself from it inside a single transaction; a failed restore changes nothing
- Still 100 % manual and on-device: no cloud, no background sync, no new permissions

### 🌍 Spanish, at home
- Spanish users are now served Spanish everywhere: terms of service, date formats, and these patch notes — previously some screens fell back to French

---

## 🐛 Bug Fixes

- Notes are no longer lost when editing a health entry
- The app recovers correctly after deleting all data (reminder settings included)
- Upgrading from older versions now creates missing reminder settings instead of a broken reminders screen

---

## 🔒 Privacy & Security

- Export and restore never contact a network — the OS share sheet and file picker are the only door, and you open it yourself
- The file picker requires no extra Android/iOS permissions
- All existing guarantees stand: offline-first, encrypted notes at rest, zero telemetry
